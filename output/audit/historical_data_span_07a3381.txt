ARCHIVAL FORMAT CHANGES & OPERATIONAL FINDINGS:
1. UDDiP Availability Window: UDDiP format (BhavCopy_NSE_CM_0_0_0_YYYYMMDD_F_0000.csv.zip) is natively
   available from January 1, 2024 to present (24+ months, 100% availability on trading days).
2. Legacy Pre-2024 Format: In 2021–2023 (36–48 month horizon), UDDiP returns 404 because NSE introduced the
   UDDiP schema in 2024. For 2021–2023, the authoritative exchange sources are:
   - sec_bhavdata_full_DDMMYYYY.csv (100% available, contains Open, High, Low, Close, PrevClose, Traded Qty).
   - MTO_DDMMYYYY.DAT (100% available, contains Security-wise Delivery Position).
3. Historical Corporate Announcements: NSE corporate announcements API and archives reliably return historical
   filings across 2021–2024 for all universe symbols.
4. Pre-Registration Mandate: Any backtest spanning 36–48 months must ingest sec_bhavdata_full for 2021–2023.
   A null result at <80% power must be pre-registered and reported as INCONCLUSIVE (not evidence of absence).
