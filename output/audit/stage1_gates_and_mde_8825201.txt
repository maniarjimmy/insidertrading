2. CO-PRIMARY SUCCESS RULES & MULTIPLE-TESTING CORRECTION (ITEM 2):
-------------------------------------------------------------------------------------------------------------------
a. Questions Answered:
   - Primary A (Announcement Lift): 'Do anomalous price/volume moves systematically precede material announcements?'
     Mechanism: Directly tests information leakage / insider trading prior to public disclosure.
   - Primary B (Post-Move Forward Excess Return): 'Is there a tradable post-move return edge?'
     Economic Value: Directly tests if market participants can profitably exploit the anomaly post-move.
b. Multiple-Testing Correction: Holm-Bonferroni Method:
   - Evaluating two co-primaries at independent alpha = 0.05 inflates family-wise error rate to ~0.0975.
   - Holm Rule: Both hypotheses tested at adjusted alpha = 0.025:
     * Sort p-values: p_(1) <= p_(2).
     * Step 1: Reject H0_(1) if p_(1) < 0.025 (alpha / 2). If not rejected, stop (neither declared significant).
     * Step 2: If H0_(1) rejected, reject H0_(2) if p_(2) < 0.05 (alpha / 1).
c. Statistical Estimators & Robustness:
   - Two-way date- and symbol-clustered standard errors (Cameron-Gelbach-Miller) for return regressions.
   - Forward excess returns winsorized at 1st and 99th percentiles to protect against microcap / penny jumps.
   - Report both Mean Excess Return and Median Excess Return (with Wilcoxon signed-rank paired test).
