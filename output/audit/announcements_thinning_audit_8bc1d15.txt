API TRUNCATION ASSESSMENT:
-------------------------------------------------------------------------------------------------------------------
Does the NSE API truncate annual queries? Let's check:
  RELIANCE 2024: Annual endpoint returns 397 records.
  RELIANCE 2025: Annual endpoint returns 164 records.
  ICICIBANK 2024: Annual endpoint returns 563 records.
  ICICIBANK 2025: Annual endpoint returns 236 records.
  TATASTEEL 2024: Annual endpoint returns 420 records.
  TATASTEEL 2025: Annual endpoint returns 162 records.
Finding: In 2024, RELIANCE returned 397 (annual) vs 399 (monthly sum, 2 record boundary difference).
NSE API does NOT artificially cap at 100 or 200 records (e.g. ICICIBANK returned 563 in a single annual call).
The dramatic drop from 2024 to 2025 is NOT API truncation, but the regulatory cessation/aggregation of
'Loss of Share Certificates' and 'Issue of Duplicate Share Certificate' disclosures (Regulation 39(3)).
When share certificate losses are excluded, material/operational filing volume was steady:
  RELIANCE:  163 (2024) -> 164 (2025)
  ICICIBANK: 184 (2024) -> 236 (2025)
  TATASTEEL: 147 (2024) -> 162 (2025)
